# EDUHUBSPOT Labs

This repository contains a small set of Java example files used for learning and demonstrating version control workflows.

## Overview

The project is focused on basic Java practice and VCS concepts. It includes simple class/example files that can be compiled and run locally.

## Repository contents

- `1.java` — Java example for demonstrating VCS concepts
- `2.java` — updated Java example with comments
- `.gitignore` — ignores local build artifacts and editor files

## Getting started

Compile the Java files with:

```bash
javac *.java
```

Run a specific class after compilation:

```bash
java 1
```

## Notes

This repository is intentionally minimal and serves as a demonstration project for Java basics and Git version control practices.
